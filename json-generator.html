Notion-Dateien vorbereiten

Erstelle aus deinen Notion-Markdown-Dateien und deinem Bilderordner eine passende Import-JSON. Deine Originalprompts bleiben vollständig erhalten.

So funktioniert es:
  1. Wähle deinen Bilderordner aus.
  2. Wähle deine Markdown-Datei aus.
  3. Tippe auf ZUORDNUNG PRÜFEN.
  4. Lade die fertige JSON herunter.
Deine Dateien werden lokal in deinem Browser verarbeitet.

Noch kein Bilderordner ausgewählt.

Noch keine Markdown-Datei ausgewählt.

Wenn du keinen Namen eingibst, verwendet das Tool die erste Überschrift aus deiner Markdown-Datei.
